# Frontend

Vue 3 + Vite + VSC (Pinia) фронтенд для Employee Task Tracker.

## Запуск

```bash
cd frontend
npm install
npm run dev
```
Структура
src/components/ — компоненты (LoginForm, Dashboard, TaskList, etc.)

src/stores/ — Pinia-сторы

src/main.js — точка входа

src/App.vue — корневой компонент

Технологии
Vue 3

Vite

Pinia
